# FRØYA – Visual Language v1.0 (Entwurf)

**Inhalt:** 6 aus dem Moodboard ausgeschnittene Referenzmotive, 4 konkrete Designanwendungen, Kontaktbogen, Guidelines und Claude-Importprompt.

**Wichtig:** Die Einzelmotive sind Zuschnitte aus einer 1672 × 941 px großen Collage, keine hochauflösenden unabhängig produzierten Masterbilder. Beispiele sind Konzepte; der Slash-Winkel ist nicht anhand der Original-SVG verifiziert.

**Integration:** Ordner ins GitHub-Repository `froya-design-system` kopieren (z. B. unter `visual-language/`), dann `CLAUDE_DESIGN_IMPORT_PROMPT.md` in Claude Design verwenden.

**Reihenfolge:** 1. Manual lesen, 2. Referenzbilder/Beispiele prüfen, 3. SVG-Winkel verifizieren, 4. in Claude importieren, 5. hochauflösende Mastermotive produzieren.
